# 🚩 CTF Writeups

Welcome to my cybersecurity Capture The Flag (CTF) writeups repository maintained by [@yuvanr-design](https://github.com/yuvanr-design). This repository serves as an archive of solutions, walkthroughs, forensic artifacts, reverse engineering notes, and automation scripts developed across various competitions and platforms.

---

## 🗂️ Repository Structure

The repository is categorized by competition platform and challenge domain:

```text
CTF-Writeups/
├── WiCySxEx0rcists-2026/   # Event-specific challenges & walkthroughs
│   └── Forensics/
├── HackTheBox/             # Ongoing Hack The Box platform machines & challenges
│   ├── Web/ | Crypto/ | Forensics/ | Pwn/ | Reverse/ | Misc/
├── PicoCTF/                # PicoCTF challenges by category
│   ├── Web/ | Crypto/ | Forensics/ | Pwn/ | Reverse/ | Misc/
└── Other-CTFs/             # Ad-hoc competitions and community CTFs
    ├── Web/ | Crypto/ | Forensics/ | Pwn/ | Reverse/ | Misc/
```

## 🛠️ Common Toolkit

- **Forensics / Steganography:** `Wireshark`, `tshark`, `binwalk`, `exiftool`, `volatility3`, `zsteg`, `steghide`, `Autopsy`
- **Reverse Engineering / Pwn:** `Ghidra`, `IDA Free`, `GDB (pwndbg/gef)`, `pwntools`, `radare2`
- **Cryptography:** `CyberChef`, `SageMath`, `PyCryptodome`, `RsaCtfTool`
- **Web Exploitation:** `Burp Suite`, `sqlmap`, `ffuf`, `httpx`
